# Fahad (0xgf-18)

Reverse engineer focused on **native binaries, .NET assemblies, and Android apps**.

I figure out how software actually works - unpacking packed and obfuscated code, reversing APKs and native libraries, recovering encrypted bytecode, and building tooling to automate the dirty work so the analysis is repeatable.

## What I do

- **Android / APK reversing** - unpacking, dex analysis, code-store decryption, rebuild and re-signing workflows
- **Native reverse engineering** - x86/x64 and ARM, ELF/PE analysis, unpacking, patching, runtime hooking
- **.NET reversing** - managed assembly inspection, deobfuscation, integrity analysis and patching
- **Security research** - packer identification and unpacking, malware triage, protocol and crypto analysis

## Toolchain

- **Languages:** C / C++, Python, C# / .NET, Kotlin
- **Analysis:** IDA Pro, Ghidra, x64dbg, dnSpy, Frida, apktool, jadx, custom scripts
- **Platforms:** Windows, Linux, Android (ARM64)

## Project

- **[unpacker-by-fahad](https://github.com/0xgf-18/unpacker-by-fahad)** - Android packer/unpacker research project for the DPT payload format: RC4 code-store key recovery, dex restore/rebuild, APK signing and validation in a single pipeline.
